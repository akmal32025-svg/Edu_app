# 📚 منصة التعلم الإلكتروني - EduApp

تطبيق Flutter تعليمي متكامل لإنشاء ونشر الدورات التدريبية مع دعم الفيديوهات والملفات.

---

## ✨ الميزات

### 🎓 إدارة الكورسات
- إنشاء كورسات جديدة مع عنوان، وصف، اسم المدرّس، وتصنيف
- تصفية الكورسات حسب التصنيف والبحث
- متابعة تقدم الطالب في كل كورس
- حذف الكورسات

### 📖 إدارة الدروس
- دعم **6 أنواع** من المحتوى:
  - 🎬 **فيديو** (MP4, MOV, AVI, MKV)
  - 📄 **PDF**
  - 📝 **مستند** (DOC, DOCX, TXT, PPTX)
  - 🎵 **صوت** (MP3, WAV, AAC)
  - 🖼️ **صورة**
  - 🔗 **رابط خارجي**
- رفع الملفات من الجهاز أو إدخال رابط URL
- تشغيل الفيديو مباشرة داخل التطبيق مع تحكم كامل
- تحديد الدروس المكتملة

### 📊 الإحصائيات
- عرض إجمالي الكورسات والدروس
- نسبة الإنجاز والتقدم

---

## 🛠️ متطلبات التشغيل

- Flutter SDK 3.0+
- Dart SDK 3.0+
- Android SDK 21+ / iOS 13+

---

## 🚀 طريقة التشغيل

```bash
# 1. استنساخ المشروع
cd edu_app

# 2. تثبيت التبعيات
flutter pub get

# 3. تشغيل التطبيق
flutter run
```

## 📁 هيكل المشروع

```
lib/
├── main.dart                    # نقطة الدخول
├── models/
│   └── course_model.dart        # نماذج البيانات
├── services/
│   ├── database_service.dart    # قاعدة البيانات SQLite
│   └── course_provider.dart     # إدارة الحالة
├── screens/
│   ├── home_screen.dart         # الشاشة الرئيسية
│   ├── course_detail_screen.dart # تفاصيل الكورس
│   ├── add_course_screen.dart   # إضافة كورس
│   ├── add_lesson_screen.dart   # إضافة درس مع رفع ملف
│   └── lesson_viewer_screen.dart # عرض الدرس
├── widgets/
│   ├── course_card.dart         # بطاقة الكورس
│   └── stats_widget.dart        # إحصائيات
└── utils/
    └── app_theme.dart           # النمط البصري
```

## 📦 التبعيات الرئيسية
