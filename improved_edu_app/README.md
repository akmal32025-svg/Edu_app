# تطبيق منصة التعلم الإلكتروني

## نظرة عامة
تطبيق تعليمي احترافي مصمم لنشر وإدارة الكورسات التعليمية والدروس التفاعلية. يوفر التطبيق واجهة مستخدم عصرية وسهلة الاستخدام لإضافة ومتابعة المحتوى التعليمي.

## المميزات الرئيسية

### إدارة الكورسات
- إضافة كورسات جديدة بمعلومات شاملة
- تنظيم الكورسات حسب الفئات
- البحث السريع عن الكورسات
- حذف وتعديل الكورسات

### الدروس التفاعلية
- دعم أنواع متعددة من المحتوى:
  - فيديوهات تعليمية
  - ملفات PDF
  - مستندات نصية
  - ملفات صوتية
  - صور توضيحية
  - روابط خارجية

### الواجهة والتصميم
- تصميم عصري متوافق مع Material Design 3
- واجهة عربية كاملة من اليمين لليسار
- ألوان جذابة وتجربة مستخدم سلسة
- رسوم متحركة انتقالية سلسة

### إدارة البيانات
- قاعدة بيانات محلية SQLite
- حفظ تقدم الطالب في كل درس
- تخزين الملفات محليًا على الجهاز
- نسخ احتياطي تلقائي للبيانات

## التقنيات المستخدمة
- **Flutter 3.27.0+**: إطار العمل الرئيسي
- **Provider**: إدارة الحالة
- **SQLite**: قاعدة البيانات المحلية
- **Video Player & Chewie**: تشغيل الفيديوهات
- **File Picker**: اختيار الملفات
- **Material Design 3**: نظام التصميم

## التثبيت والإعداد

### 1. تثبيت Flutter
قم بتحميل Flutter SDK من الموقع الرسمي:
```bash
https://flutter.dev/docs/get-started/install
```

### 2. نسخ المشروع
```bash
flutter create --org com.example --project-name edu_app edu_app
cd edu_app
```

### 3. نسخ ملفات المشروع
انسخ محتويات مجلد `lib/` و `pubspec.yaml` إلى المشروع الجديد

### 4. تثبيت الحزم
```bash
flutter pub get
```

### 5. تشغيل التطبيق
```bash
flutter run
```
